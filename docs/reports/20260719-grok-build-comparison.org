Read of SpaceXAI's *Grok Build* (=github.com/xai-org/grok-build=, a Rust terminal
AI coding agent — the closest production analog to guile-sage) for features/gaps
worth rolling into sage. Ideas/patterns only.

*License:* grok-build first-party code is *Apache-2.0* (it itself ports openai/codex
+ sst/opencode under §4(b) change notices). Patterns are borrowable *with
attribution*; no code copying (and none needed — sage is Guile; the value is
architectural).

*Path framing.* grok-build: interactive TUI · headless =-p= (CI) · *ACP*
editor-embedding. guile-sage: interactive REPL · =-p= one-shot · *MCP server*.
The interesting delta is the third path + a set of runtime crates that map onto our
open roadmap themes (CAVA = Theme 2, memory = Theme 3).

* Verdicts on the called-out questions
- *ACP vs our MCP-server — 3rd editor path?* They solve *opposite* problems: MCP-server
  makes sage a *tool provider* others call (shipped, M1/M2 live); ACP makes sage a
  *full agent an editor drives* (editor owns the loop, calls back for fs/terminal/
  permission). Full ACP is a *large* lift for a Guile reference and overlaps the
  MCP-server play. *Do not build full ACP now* — extract only the
  =session/request_permission= reverse-channel (item 5). Revisit a minimal ACP
  =session/{new,prompt,update}= subset only if a third consumer (e.g. Zed) appears.
- *Strongest Theme 2 (CAVA) wins:* items 1 (edit attribution), 3 (deny-glob policy),
  5 (permission reverse-channel) — all thread through the =execute-tool= choke point
  RFC-004 already identifies.
- *Strongest Theme 3 win:* item 6 — a working reference for the Dolt-backed queryable
  substrate + the "compaction becomes eviction" thesis.

* Deliberately do NOT copy (scope/complexity mismatch for a Guile reference)
- gRPC/protobuf tool backbone (=xai-grok-tools-api=, =xai-computer-hub-*=) — massive
  dispatch for a 34-tool registry; our alist + stdio JSON-RPC is right-sized.
- Dynamic tool search/discovery (=ToolSearchIndex=, =search_tool=) — only pays at
  hundreds of tools.
- =xai-fast-worktree= (CoW/BTRFS snapshot pools) — OS-specific perf, irrelevant to a
  reference.
- =xai-grok-plugin-marketplace= — a product-distribution feature, not a boundary.
- =xai-sqlite-journal= (NFS-aware WAL) — Dolt already owns our persistence (Theme 3).
- TUI/media stack (=xai-ratatui-*=, =xai-grok-voice=, video/image gen, =xai-mixpanel=)
  — UI polish + proprietary media + Mixpanel (we have OTLP, §10).
- Full ACP — take the pattern, not the protocol.
- *Note:* grok's sandbox is genuinely *kernel-enforced* (Landlock/Seatbelt + seccomp).
  We can't match that in-process/portably — enforcement stays the root jail operator's
  job (our privilege boundary); we adopt only the *policy expression* (item 3).
