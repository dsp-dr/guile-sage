* Group C — real bug / real gap (fix first)
** C1. Id-less =tools/call= still emits a reply  /(reference bug)/
Spec §4/§15.2: an *absent*-id =tools/call= is a notification (no reply). But
=on-tools-call= (=mcp-server.scm:85=) always replies; absent id → =#f= →
=reply= emits ="id":false= (=util.scm:177=) — a spec violation AND malformed
JSON-RPC 2.0. The generic =else= branch (=:127=) already guards with =(if id …)=;
the named handlers do not.
- *Fix (code):* suppress emission when id is absent (=#f=) in the request handlers;
  keep =id: null= (the ='null= sentinel, truthy) → reply. Preserves no-oracle.
- *Lock:* PBT — absent-id =tools/call= ⇒ *no* stdout line; =id:null= ⇒ exactly one
  reply with =id= null. + a =mcp-smoke.sh= case.

** C2. §15.7 invariant has a false Handbook anchor + no PBT lock
HANDBOOK L3.3 (=:348,376-377=) claims the round-trip/=cdata-no-escape= properties
are guarded in =test-pbt.scm= — they are NOT there (only wrap-direction unit tests
in =test-prompt-injection.scm=; no =unwrap-tool-result= in =src/=).
- *Fix:* (1) add the two *expressible* wrap-side PBT properties: =cdata-no-escape=
  (arbitrary bytes ⇒ wrapped output has no early-closing =]]>=) + the count
  invariant; (2) *decide* whether to add an in-source =unwrap-tool-result= so the
  true round-trip inverse is testable in the reference (recommended: yes, to make
  §7's inverse a first-class regression-locked property); (3) correct the Handbook
  anchors once the property lands (facts-anchor discipline).

* Group B — open question (needs a call)
** B1. Structured JSON-RPC =id= (=id:{}=, =id:[]=)
§4 pins null/{}/absent for *params* + id:null-vs-absent, but not a structured id.
JSON-RPC 2.0 requires =id ∈ {string,number,null}=. Reference echoes it verbatim
(=mcp-server.scm:117=) → ="id":{}=, an invalid reply.
- *Recommended:* structured id → =-32600= with =id: null= (conformant, removes a
  fingerprinting wire-shape, matches the fail-closed / never-emit-malformed
  posture). Alt: accept+echo, documented out-of-contract. *Your call.*
- *Lock:* PBT — id = object/array/bool ⇒ =-32600=, =id: null=, no echo.
